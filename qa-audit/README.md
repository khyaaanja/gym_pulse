# GymPulse QA Audit

This directory contains the complete QA audit for the GymPulse application.

## Structure

- `00-project-inventory/` - Architecture, roles, routes, features, and API inventory
- `01-test-plan/` - Test strategy, scope, risk register
- `02-test-cases/` - Test cases for authentication, roles, features, APIs, security, A11y/perf
- `03-execution-results/` - Test execution results, logs, blocked tests
- `04-evidence/` - Screenshots, console logs, network traces
- `05-bug-reports/` - Individual bug reports (BUG-001.md, etc.)
- `06-security/` - Security findings and permission matrices
- `07-coverage/` - Feature coverage, role coverage, requirements traceability
- `08-performance-accessibility/` - Performance and accessibility reports
- `09-final-reports/` - Executive summary, final report, prioritized fix plan
- `history/` - Audit timeline

## Running the Audit

See `01-test-plan/test-strategy.md` for the execution plan and strategy.

## Evidence

All screenshots, console logs, and network traces are stored in `04-evidence/`. No credentials, tokens, or cookies are stored in evidence files.
